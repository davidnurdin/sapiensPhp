游戏介绍

你是 Torgan，Pieds-Agiles 部落的年轻猎人。你以第一人称视角穿行于辽阔的山谷：群山、森林、泉水、云朵与风暴。昼夜交替，饥饿、干渴和疲惫不断消磨着你。你会遇到狼、熊、兔子，以及其他部落的人：这时就得以侧视角战斗，用斧头、标枪或赤手空拳……或者选择交谈、互赠礼物、结交盟友。

打制燧石来制作武器，采集浆果和根茎，处理伤口，在篝火旁入睡。在这里，计谋与外交往往比武力更管用。

任务

你的部落首领 Hognor 会交给你一个比一个更艰难的考验：

  1. 带回食物：部落正在挨饿。
  2. 向 Yeux-Malins 取得生命药水，因为孩子们误食了有毒的浆果。
  3. 接受 Bras-de-Roc 的挑战：打败他们的首领，夺取象牙斧。
  4. 夺回被 Hyènes-Folles 偷走的圣杖。
  5. 最后……让强者为尊的法则来选出新首领。

悠久的历史

  • 1986 年 — 首个版本，用汇编语言为 Thomson MO5、TO7/8/9 和 Amstrad CPC 编写，之后又用 C 语言为 PC 重写。
  • 1987 年 — 为 Atari ST 推出色彩更丰富的版本。
  • 1996 年 — C 语言源代码从箱子里重见天日：推出 MacOS 和 Windows 版本。
  • 2017 年 — Sapiens 成为免费软件。
  • 2018 年 — Myriad 公开源代码，采用 GNU GPL v3 许可证。
  • 如今 — 移植到 PHP，可在浏览器中游玩。

100% PHP

这个版本是将 2018 年发布的 C 语言源代码逐个函数忠实移植到 PHP 的成果，基于 JumPHP 框架。同一份代码既能在电脑上运行（PHP + SDL2），也能在浏览器中运行（编译为 WebAssembly 的 PHP）。精灵图、音效和文字均来自原版游戏。

源代码：github.com/davidnurdin/sapiensPhp · 原始源代码：Myriad 的 Sapiens 开源页面。
